# Certify

> 📦 **Archived** — This project has been archived due to the deprecation of one of its key dependencies, **Deta Base**, which is no longer supported. As a result, the application is no longer functional.

**Certify** is a Streamlit-based application designed to generate and distribute certificates efficiently. It allows users to input participant data and automatically create personalized certificates, simplifying the certification process for events, workshops, and academic activities.
